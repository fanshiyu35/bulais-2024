# BulAIS 2024 Workshop Website

Static website for the **2024 BulAIS Workshop on Information Systems & Digital Innovation**, held at the Faculty of Mathematics and Informatics of Sofia University "St. Kliment Ohridski", 25–26 October 2024.

BulAIS — **Българска асоциация за информационни системи** — is the Bulgaria Chapter of the international Association for Information Systems (AIS).

## Workshop

- **Dates:** 25–26 October 2024
- **Venue:** FMI Sofia University, 5 James Bourchier Blvd., Sofia 1164, Bulgaria
- **General Chair:** Prof. Kalinka Kaloyanova (FMI Sofia University)
- **Proceedings:** CEUR Workshop Proceedings, ISSN 1613-0073, Vol-3852 (forthcoming)

## Site map

- `index.html` — workshop home, key dates
- `about.html` — about BulAIS and the workshop
- `cfp.html` — call for papers, submission categories, fees
- `committee.html` — programme and steering committees
- `schedule.html` — two-day programme
- `venue.html` — Sofia, FMI, travel, accommodation
- `proceedings.html` — table of contents
- `paper_01.html` … `paper_06.html` — full paper pages

## Design

Balkan-academic visual identity: warm burgundy (`#722f37`) and gold (`#c4a35a`), traditional serif typography (Cormorant Garamond, Old Standard TT, PT Serif), parchment background, and Cyrillic-inspired ornamental motifs evocative of Sofia University and the wider South-East European academic tradition.

## Build

The site is plain HTML/CSS — no build step required. Open `index.html` directly or serve the directory with any static-file server.

```
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.
